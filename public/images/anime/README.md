# /public/images/anime

Reserved for licensed imagery. This project ships **no** third-party anime images:
official Beyblade X artwork and photography are copyrighted by Takara Tomy / Hasbro,
and no reuse licence was available for this independent fan project.

If you obtain permission to use official assets, place optimised WebP/AVIF files here and
reference them from `lib/products.ts` (`image` field) or the relevant component.
Record each file's source and licence in /ASSETS.md.
